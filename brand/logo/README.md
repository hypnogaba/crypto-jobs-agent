# NextRole — знак «наступна сходинка»

Три пройдені сходинки і четверта клітинка попереду, ще не зайнята.
Стоїть на тій самій міліметрівці, що й сайт; кольори — з `web/src/app/globals.css`:
ink `#202123`, paper `#fbfbfa`, ember `#b34a1e` (світла тема) / `#e58650` (темна).

## Що брати

| Файл | Куди |
|---|---|
| `png/logo-512.png` | аватар у Telegram (@BotFather → `/setuserpic`), профілі, месенджери |
| `png/logo-1024.png` | усе, де треба запас якості: сторінки, презентації, друк на екран |
| `logo.svg` | вектор, масштабується без втрат |
| `favicon.ico`, `png/logo-180.png` | вкладка браузера й іконка на iOS |
| `mark.svg` | самі сходинки без тла; успадковує колір тексту через `currentColor` |
| `logo-ink.svg`, `logo-paper.svg` | стримані варіанти: на чорнилі та на папері |
| `alternates/` | шість початкових ескізів, зокрема монограма N |

## Правила

- Не міняти пропорції і не додавати обведення. Знак уже має відступ від краю —
  Telegram обрізає аватар у коло, і при такій побудові нічого не зрізається.
- На кольоровому тлі брати `logo.svg` як є, суцільним колом. Ember на ember не ставити.
- Мінімальний розмір — 20 px. Нижче сходинки зливаються.

## Перегенерувати

```sh
./gen.sh
```

Змінює все одразу: SVG, PNG усіх розмірів і `favicon.ico`. Потрібні macOS `sips`
і Chrome (растеризація).
