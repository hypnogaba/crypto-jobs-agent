# Керування щоденною рутиною

- Перегляд і керування: https://claude.ai/code/routines
- Видалення рутини можливе тільки через веб-інтерфейс (API не підтримує delete)
- Секрети (X API токен, Telegram bot токен) вписані буквально в текст промпту рутини на сервері — НЕ в git. Якщо потрібно ротувати ключ: оновити рутину через `RemoteTrigger {action: "update"}` з новим текстом промпту.
- Дедуп-стан: `data/seen_tweets.json` у репозиторії, оновлюється й пушиться самою рутиною щодня.
- Список акаунтів: `data/accounts.json`, редагується вручну за потреби (додати/прибрати акаунти).
- Відомий ліміт: 6551.io Plus-тариф, ~20,000 повідомлень/місяць.

## Відома проблема: новий репозиторій не одразу доступний хмарним рутинам

Після створення нового GitHub-репозиторію (або перепідключення GitHub App) список репозиторіїв, доступних `RemoteTrigger`/хмарним рутинам, синхронізується з затримкою — навіть якщо в UI вибору репозиторію (claude.ai/code/routines/new) репозиторій уже видно. Ознака: `RemoteTrigger {action: "create"}` повертає `403 permission_error: "You don't have access to a repository this routine uses."`, хоча інший (старіший) репозиторій того самого акаунту створюється без проблем.

Що допомагає: почекати (десятки хвилин), зробити додатковий push у репозиторій, спробувати ще раз.
