## Фаза 3 — сайт

**Код готовий і протестований локально** (`web/` — Next.js, MySQL/Prisma, mock AI, Telegram/email вибір). Онбординг → база → дашборд → налаштування — усе працює у `npm run dev`.

**Деплой на shared-хостинг — заблокований.** П'ять підтверджених технічних бар'єрів (повний розбір: `docs/shared-hosting-findings.md`):
1. Node.js Selector не встановлений на сервері (адмінська функція)
2. CPU-throttling білду (12 сек CPU за 2.5 год)
3. Навіть легкий runtime-процес сам помирає за ~10-20 сек без явної причини
4. Довільні зовнішні порти заблоковані
5. SSH crontab зламаний (Python-помилка на боці CloudLinux)

**Рішення, на якому зупинились:** переписати сайт на PHP замість Next.js/Node — це єдиний стек, який цей хостинг підтримує нативно, без throttling і без вбивства процесів. PHP + прямий MySQL (той самий, уже перевірений) + `curl` для Telegram + вбудований `mail()` замість Resend + панельний cron замість SSH. **Ще не почато писати.**

## Чого ще бракує

- Домен — у процесі купівлі (не підтверджено завершення)
- Resend — вирішили не використовувати, замінити на `mail()` (див. вище)
- Anthropic API-ключ — свідомо відкладено, сайт працює на mock-даних
- PHP-переписування сайту — не почато
- Автоматизація щоденної Х-перевірки — не вирішена (сесійний cron не переживає перезапуск)
